# 개발 문서 안내

이 문서 묶음은 [제품 요구사항](1_REQUIREMENTS.md)을 기준으로 구현·검증·운영할 때 참고하는 기준 문서다. 요구사항에 명시되지 않은 내용은 결정이 필요한 가정으로 표시했으며, 확정되면 요구사항과 관련 문서를 함께 갱신한다.

## 문서 목록

1. [제품 요구사항 명세](1_REQUIREMENTS.md): 목표, 범위, 기능 및 품질 요구사항, 수용 기준
2. [시스템 설계](2_SYSTEM_DESIGN.md): 구성요소, 데이터 흐름, 오류 처리, 제안 디렉터리 구조
3. [설정 및 인터페이스 규격](3_CONFIGURATION.md): `.env`, CLI, 산출물 계약
4. [프롬프트 규격](4_PROMPT_SPECIFICATION.md): 파일 기반 프롬프트와 LLM 출력 계약
5. [테스트 계획](5_TEST_PLAN.md): 단위·통합·수용 테스트와 완료 기준
6. [운영 가이드](6_OPERATIONS.md): 설치, 실행, cron, 로그, 장애 대응
7. [개발 계획](7_IMPLEMENTATION_PLAN.md): 단계별 구현 순서와 완료 산출물

## 문서 우선순위

요구사항 간 충돌은 `0_RFP.md`의 목적 및 명시 요구사항을 우선한다. 구현 세부사항은 이 문서 묶음의 제안을 기준으로 삼되, 아직 확정되지 않은 항목은 제품 결정 후 반영한다.
