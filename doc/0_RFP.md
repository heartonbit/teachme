# Teach me

## 목적

이 프로그램은 LLM AI Model을 이용하여 매일 지정된 미디어의 뉴스를 모니터링하고 적절한 수준의 텍스트로 재생성하여 읽기공부를 위한 학습자료를 생성한다. 

## 기술

가능한 한 shell 스크립트를 사용하되 필요한 경우 python을 사용할 수도 있다. 

## LLM

LLM은 OpenAI 방식의 API를 사용하는 모든 provider를 사용할 수 있고, .env 파일에 필요한 정보를 저장하도록 한다. 

프롬프트 또한 따로 파일로 관리한다. 

## 학습언어

학습언어는 English, French 등으로 .env에 지정할 수 있도록 한다. 

## 결과물

생성된 학습자료는 yyyy-MM-dd 폴더 이름으로 result 폴더 아래에 저장하도록 한다. 

## 명령어

cron 명령으로 실행할 수 있는 shell 스크립터 명령어를 제공한다. 

## 디버깅

오류시 디버깅을 위해 --debug 파라미터를 사용할 수 있도록 개발한다. 

## 뉴스 미디어

모니터링할 뉴스 미디어 URL도 .env에 관리할 수 있도록 한다. 

디폴트로 영국: BBC, Guardian, 미국: CNN, AP통신, 프랑스: 르몽드, 벨기에: 브뤼셀 타임스 (https://www.brusselstimes.com/)
